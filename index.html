Logic Lesson: If... Then... Else

In programming and English, we use this to make decisions. If a condition is true, we do one thing. Otherwise (else), we do something different.

Think of it like a fork in the road!

  • IF is the question you ask (e.g., "Is it raining?").
  • THEN is what you do if the answer is YES (e.g., "Use an umbrella").
  • ELSE is what you do if the answer is NO (e.g., "Wear sunglasses").

Listen to an example:

If it is raining, then take an umbrella, else wear sunglasses.
